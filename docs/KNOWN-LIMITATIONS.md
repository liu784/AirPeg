# 已知限制与验收边界

- 1.8.5 为预览发布准备版。P4 1.8.3 视觉已获用户认可；P5 稳定性最终验收尚待完成，不宣称正式稳定版 PASS。
- 实时设置玻璃采用 Desktop Duplication / D3D11 / D3D9Ex / WPF D3DImage，是 Windows 光学近似，并非 Apple 引擎。支持连续更新，未恢复冻结快照或内容保护方形蒙版。
- 当前设置窗口只从所在显示输出取样；跨屏窗口、HDR、旋转输出、远程桌面、驱动重置及部分显卡组合可能触发安全降级。
- 自身窗口采集排除使用微软文档中的 WCA_EXCLUDED_FROM_DDA；微软对 SetWindowCompositionAttribute 通用入口仍有“不推荐”标注。初始化失败时停止实时采集并保留可操作的低特效 UI，不尝试系统 Hook。
- Windows 10 19045 / 1920×1080 / 100% DPI 有实测记录。Windows 11、125% / 150% / 200% DPI、多显示器插拔、锁屏及远程会话尚未全部覆盖，未标记通过。
- 现有 P1/P2/P3 人工验收功能继续保留；发布准备的源码构建不替代所有版本上的真实文件拖放、系统截图及编辑操作。
- 品牌后 1.8.5 EXE 的独立编辑自检已通过，但旧版本的兼容单实例阻止了本轮完整独立托盘重测；发布前仍需完成正常启动 / 退出确认。
- 演示视频使用真实原生窗口及程序驱动操作，片内保留说明；不是完整实体鼠标录屏，也不把编码 60 FPS 等同于每秒 60 次独特玻璃帧。
- 便携配置和截图位于 Data。历史持久化默认关闭；用户启用后应选择合适容量和过期策略，升级前备份私人数据。
- 默认快捷键可能被其他软件占用。软件提示冲突并允许重新指定，不抢占其他应用或改系统快捷键。
- 当前已认可完整视频实测为 HEVC / 30 FPS / 90 秒，与旧 H.264 校验记录不同。此次按现有文件原样上传，未重编码或补充片头。部分浏览器不能直接解码 HEVC，可下载到兼容播放器。
